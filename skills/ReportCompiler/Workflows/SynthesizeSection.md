# Synthesize Section Workflow

## Purpose
Write a single assessment section based on gathered sources.

## Inputs

- Section topic (from outline)
- Relevant source content (from GatherSources)
- Score for this area (from ExtractScores)
- Key questions to address (from outline)
- Overall themes/angles (from outline)

## Process

### Step 1: Gather Section Materials

Collect all content relevant to this section:
- Scorecard data for this area
- Quotes from interviews/transcripts
- Data points from analysis
- Observations from client materials
- Notes from project files

### Step 2: Analyze Content

Review materials to identify:
1. **Current state** — What exists today
2. **Strengths** — What works well
3. **Gaps** — What's missing or broken
4. **Root causes** — Why gaps exist
5. **Impact** — Business consequences
6. **Evidence** — Specific supporting data

### Step 3: Draft Narrative

Using AssessmentSection template:

```markdown
## [Section Name]

**Maturity Score: X.X / 5.0**

### Current State

[Write 2-3 paragraphs describing the current situation. Be specific and factual. Include context about scale and scope.]

**Paragraph 1:** Overview of how this function operates today
**Paragraph 2:** Key strengths and what works
**Paragraph 3:** Primary challenges and gaps

### Key Findings

[Select 3-5 most important findings. Each should have:]

1. **[Finding Title]**
   - **Observation:** [What we saw]
   - **Evidence:** [Data, quote, or specific example]
   - **Impact:** [Business consequence]

### Gap Analysis

[Create comparison table showing current vs. target state]

| Dimension | Current | Target | Gap |
|-----------|---------|--------|-----|
| ... | ... | ... | ... |

### Supporting Evidence

[Include 1-2 direct quotes and 3-5 data points]

> "[Quote from interview or document]"
> — [Source]

### Implications

[1-2 paragraphs on what this means for the client]
```

### Step 4: Add Visual Suggestions

For each section, suggest at least one visual:

```markdown
[VISUAL: Radar chart comparing sub-dimensions within this area]
- Type: Radar chart
- Data: Sub-scores from scorecard
- Callout: Highlight lowest dimension

[VISUAL: Process flow showing current state with bottlenecks marked]
- Type: Flowchart
- Data: Based on SOP review
- Callout: Mark where breakdowns occur
```

### Step 5: Cross-Reference

Link section to:
- Related findings in other sections
- Recommendations it informs
- Appendix details if applicable

## Writing Guidelines

### Tone
- Objective, not judgmental
- Specific, not vague
- Evidence-based
- Balanced (acknowledge positives)

### Structure
- Lead with the score
- Current state before gaps
- Evidence for every claim
- Implications connect to business

### Length
- Current state: 200-400 words
- Each finding: 50-100 words
- Implications: 100-200 words
- Total section: 600-1000 words

### Common Mistakes to Avoid
- Being too vague ("communication could improve")
- Missing evidence ("we observed issues")
- Only negative ("everything is broken")
- Prescriptive language (save for recommendations)
- Jargon without explanation

## Quality Checklist

- [ ] Score matches source scorecard
- [ ] At least 3 specific findings
- [ ] Each finding has evidence
- [ ] At least one direct quote
- [ ] Gap analysis table completed
- [ ] Visual suggestion included
- [ ] Implications section completed
- [ ] Related recommendations noted
