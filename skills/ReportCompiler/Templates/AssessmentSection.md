## Scoring Guide

| Score Range | Level | Characteristics |
|-------------|-------|-----------------|
| 1.0 - 1.4 | Initial | No formal process, completely reactive |
| 1.5 - 2.4 | Developing | Basic process exists, inconsistent execution |
| 2.5 - 3.4 | Defined | Documented process, regular measurement |
| 3.5 - 4.4 | Managed | Data-driven, continuous improvement |
| 4.5 - 5.0 | Optimized | Predictive, innovative, industry-leading |

---

## Writing Guidelines

### Current State Narrative
- Start with what exists (not what's missing)
- Be specific about how things work today
- Include context about scale (team size, volume, etc.)
- Acknowledge any recent changes or initiatives

### Findings
- Limit to 3-5 key findings per section
- Each finding should be evidence-based
- Impact should connect to business outcomes
- Use specific numbers when available

### Evidence
- Include at least one direct quote per section
- Data points should come from client sources
- Reference specific documents/interviews
- Be transparent about data limitations

### Implications
- Connect to business outcomes
- Explain the "so what"
- Set up the recommendation section
- Avoid being prescriptive here (save for recommendations)

## Common Assessment Areas

1. **Capacity Planning** — Forecasting, scheduling, optimization
2. **Real-Time Management** — Intraday operations, adherence, queue management
3. **Technology** — Systems, integrations, automation
4. **Process** — SOPs, variance analysis, feedback loops
5. **Workforce Stability** — Attrition, engagement, scheduling flexibility
6. **Talent** — Skills, training, career development
7. **Governance** — Metrics, reporting, accountability
8. **Employee Experience** — Schedule preferences, work-life balance
