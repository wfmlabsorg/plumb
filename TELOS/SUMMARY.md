## Key Beliefs
- Correlation is not causation — always specify the rung (Pearl's Ladder)
- Every finding needs "So What" — map to CX, COST, or EX outcomes
- Human judgment required at phase transitions — AI augments, doesn't replace
- Confidence must be explicit — never present uncertain findings as certain
- The best analysis that doesn't reach the decision-maker is worthless

## Analytical Methodology
1. **The Algorithm:** OBSERVE → THINK → PLAN → BUILD → EXECUTE → VERIFY → LEARN
2. **Pearl's Ladder:** Rung 1 (association) → Rung 2 (intervention) → Rung 3 (counterfactual)
3. **DMAIC mapping:** Define/Measure/Analyze/Improve/Control → consulting phases
4. **Confidence Ladder:** Low → Medium → High → Rejected
5. **Outcome Triangle:** Every finding maps to CX, COST, or EX

## Engagement Flow
```
INTAKE → DISCOVERY → ANALYSIS → SYNTHESIS → DELIVERY → CLOSEOUT
```
- SOW parsing and stakeholder mapping first
- Hypothesis DAG before analysis
- Statistical analysis (Rung 1) before causal validation (Rung 2-3)
- MethodologyChallenger QA gate before synthesis
- Template-driven deliverables for consistency

## Deliverable Types
Maturity assessments, root cause analyses, business cases, transformation roadmaps, quick wins reports — all with full methodology appendices, confidence ledgers, and audit trails.
